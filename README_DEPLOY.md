# Руководство по облачному запуску 24/7 и установке на телефон (PWA)

Мобильный Web-HUD **GGPoker Spin & Gold Leaderboard** создан для круглосуточной работы **24/7 в облаке** (без включённого компьютера). Вы можете в любой момент открыть ссылку на смартфоне (iPhone или Android), видеть своё место в лидерборде, отрыв от преследователя, сколько очков осталось до следующего приза и таймер до конца зачётного дня (08:00 UTC).

---

## ⚡ Вариант 1: Мгновенная облачная ссылка (Vercel / Render.com — 24/7 бесплатно)

### А. Через Render.com (Бесплатный облачный сервер 24/7)

**Render.com** предоставляет бесплатный облачный Python-сервер с автоматическим HTTPS-сертификатом.

1. **Загрузите проект на GitHub**:
   - Репозиторий проекта загружается в ваш аккаунт GitHub (приватный или публичный).

2. **Войдите на Render.com**:
   - Откройте [https://render.com/](https://render.com/) и войдите через свой аккаунт GitHub.

3. **Автоматический запуск в 1 клик (Blueprint)**:
   - Нажмите **New +** -> **Blueprint**.
   - Выберите репозиторий `GG_LEADERBOARD_MOBILE`.
   - Render автоматически прочитает файл [`render.yaml`](render.yaml) и сам настроит Python-сервер.
   - Нажмите **Apply**.

4. **Или ручная настройка (за 30 секунд)**:
   - Нажмите **New +** -> **Web Service** и выберите репозиторий.
   - Укажите параметры:
     - **Name**: `gg-leaderboard-mobile`
     - **Region**: Frankfurt (или ближайший к вам)
     - **Runtime**: `Python`
     - **Build Command**: `pip install -r requirements.txt`
     - **Start Command**: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
     - **Plan**: `Free`
   - В разделе **Environment Variables** (Переменные окружения) задайте:
     - `APP_PIN`: ваш личный секретный ПИН-код (по умолчанию `7777`).
     - `HERO_NICKNAME`: (необязательно) ваш никнейм на GGPoker по умолчанию.

5. **Откройте вашу постоянную ссылку**:
   - Через 1–2 минуты Render выдаст постоянный адрес вида `https://gg-leaderboard-mobile.onrender.com`.
   - Эта ссылка работает **24/7 при полностью выключенном компьютере** через мобильный интернет (4G/5G) и любой Wi-Fi!

## ⚡ Вариант 2: Облачный деплой через Railway.app

**Railway.app** поддерживает мгновенную сборку из [`Procfile`](Procfile) или [`Dockerfile`](Dockerfile).

1. Зайдите на [https://railway.app/](https://railway.app/) через GitHub.
2. Нажмите **New Project** -> **Deploy from GitHub repo** и выберите `GG_LEADERBOARD_MOBILE`.
3. Во вкладке **Variables** добавьте переменную `APP_PIN` (например, `7777`).
4. Во вкладке **Settings** -> **Networking** нажмите **Generate Domain**, чтобы получить постоянную HTTPS-ссылку.

## 🐳 Вариант 3: Запуск через Docker (для своего VPS-сервера)

Если у вас есть собственный виртуальный сервер (VPS), вы можете запустить контейнер одной командой:

```bash
# 1. Сборка образа Docker
docker build -t gg-leaderboard-mobile .

# 2. Запуск контейнера в фоне 24/7 с вашим ПИН-кодом
docker run -d \
  --name gg-hud \
  --restart always \
  -p 8000:8000 \
  -e APP_PIN=7777 \
  -e PORT=8000 \
  gg-leaderboard-mobile

# 3. Проверка статуса
curl http://localhost:8000/api/health
```

## 📱 Как добавить иконку приложения на экран телефона (PWA)

Чтобы открывать HUD как полноценное мобильное приложение на весь экран (без адресной строки браузера):

### На iPhone (через браузер Safari):
1. Откройте вашу облачную ссылку (`https://...`) в браузере **Safari**.
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх внизу экрана).
3. Пролистайте меню вниз и выберите **«На экран „Домой“» (Add to Home Screen)**.
4. Нажмите **«Добавить»** в правом верхнем углу.
5. На рабочем столе iPhone появится золотая иконка **GG HUD**!

### На Android (через браузер Chrome):
1. Откройте ссылку в браузере **Chrome**.
2. Нажмите на **три точки** в правом верхнем углу.
3. Выберите **«Установить приложение»** или **«Добавить на главный экран» (Add to Home Screen)**.
4. Подтвердите установку — приложение появится на рабочем столе телефона.

## 💻 Вариант 4: Локальный запуск на ПК (необязательно)

Если когда-нибудь понадобится запустить сервер локально на компьютере:
- Дважды кликните по файлу [`START_MOBILE_HUD.bat`](START_MOBILE_HUD.bat) или выполните `python run_server.py`.
- Примечание: если на ПК включён VPN с блокировкой локальной сети (KillSwitch в AmneziaVPN), локальный IP (`192.168.x.x`) с телефона будет перехватываться VPN. Поэтому **облачная ссылка 24/7 (Вариант 1)** намного удобнее — ей не мешает VPN и не нужен включённый компьютер.

## 🔐 Безопасность и доступ только для вас

- **Защита ПИН-кодом**: При первом входе сайт запрашивает секретный ПИН-код (переменная `APP_PIN`, по умолчанию `7777`).
- **Запоминание устройства**: После ввода ПИН-кода телефон сохраняет защищённый токен на 30 дней — вводить пароль каждый раз не нужно.
- **Как сменить ПИН-код**: Достаточно изменить значение `pin` в файле `config.json` или переменную `APP_PIN` в панели облака.
